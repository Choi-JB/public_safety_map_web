# 작업명세서: 인프라 마커 ↔ 격자 분리 (중심+반경)

| 항목 | 내용 |
| :--- | :--- |
| 작성일 | 2026-07-29 |
| 갱신일 | 2026-07-29 (FE 구현·토글 UX 반영) |
| FE 레포 | `public_safety_map_web` |
| BE 레포 | `public_safety_map_backend` |
| 담당 | 지도표시팀 (BE·FE 협업) |
| 상태 | **FE·BE 구현 완료** (DEBUG Circle은 QA용 유지) |

---

## 1. 목적

- 인프라(CCTV·경찰서·소방서·편의점) 마커를 **격자 선택에 종속시키지 않는다.**
- 사용자 **지도 view(중심·줌)** 에 맞춰 인프라를 자동 표시한다.
- 범위 방식 **B**: `지도 중심 + 줌 레벨 → 반경(원)`.

---

## 2. 현재 vs 목표 (달성)

| 구분 | 이전 | 현재 |
| :--- | :--- | :--- |
| 격자 | viewport → 폴리곤 | 동일 + **표시/등급 토글** |
| 격자 클릭 | 인프라 마커 + 상세 | **왼쪽 패널 상세만** |
| 인프라 마커 | `GET /grids/:id/infrastructures` | **`GET /infrastructures` 중심+반경** |
| 주변 필터 | `infraType` 단일(라디오) | **`infraVisible` + `visibleInfraTypes` 토글** |
| 행사·제보 | viewport bounds | 동일 |

---

## 3. 동작 흐름

```
지도 idle (이동·줌 종료)
  → center = map.getCenter()
  → level  = map.getLevel()
  → radius_m = levelToRadiusM(level)   // app/map/infraRange.ts
  → (DEBUG) Circle(center, radius_m) — stroke만, fillOpacity 0
  → GET /infrastructures?lat&lng&radius_m
  → visibleInfraTypes 로 FE 필터
  → 기존 인프라 마커 삭제 후 재생성

infraVisible === false
  → API 스킵, 마커·Circle 전부 제거
```

패널(격자 탭):

```
격자 클릭 → setSidePanelTab("grid") + detail
  → GET /grids/:id/detail
  → GET /grids/:id/infrastructures  (집계·목록만, 지도 마커와 무관)
```

## 4. BE 작업

### 4.1 API

- **경로**: `GET /infrastructures`
- **기존 유지**: `GET /grids/:id/infrastructures` (패널 집계)

### 4.2 쿼리

| 파라미터 | 필수 | 설명 |
| :--- | :--- | :--- |
| `lat` | Y | 지도 중심 위도 |
| `lng` | Y | 지도 중심 경도 |
| `radius_m` | Y | 반경(미터) |
| `type` | N | 단일 타입 (FE는 현재 **미사용**, 전체 수신 후 FE 멀티 필터) |

### 4.3 BE 완료 조건

- [x] `GET /infrastructures` 동작
- [x] `type` 필터 동작 (BE)
- [x] 잘못된 쿼리 시 422
- [x] 기존 `GET /grids/:id/infrastructures` 회귀 없음

## 5. FE 작업 (구현 반영)

### 5.1 대상 파일

| 파일 | 역할 |
| :--- | :--- |
| `app/map/kakaoMap.tsx` | 중심+반경 조회, 마커, DEBUG Circle, OFF 시 clear |
| `app/map/infraRange.ts` | `levelToRadiusM`, `DEBUG_INFRA_RANGE_CIRCLE` |
| `store/mapStore.ts` | `infraVisible`, `visibleInfraTypes`, `INFRA_TYPES` |
| `lib/api/types.ts` | `InfraRadiusQuery` 등 |
| `app/map/MapControls.tsx` | 주변 ON/OFF + 타입 체크 토글 |
| `app/map/CityEventsPanel.tsx` | 격자 탭 인프라 개수 = 격자 API |

### 5.2 줌 → 반경 (`infraRange.ts`)

| `map.getLevel()` | `radius_m` |
| :--- | :--- |
| ≤ 4 | 500 |
| 5 | 1000 |
| 6 | 1500 |
| 7 | 2500 |
| 8 | 4000 |
| ≥ 9 | 5000 |

### 5.3 store / UI

| 상태 | 의미 |
| :--- | :--- |
| `infraVisible` | false면 마커·원 전부 제거, API 스킵 |
| `visibleInfraTypes` | CCTV·경찰서·소방서·편의점 멀티 토글 |

칩 라벨 예: `주변` / `주변 · CCTV` / `주변 · 2종` / `주변 · 숨김`

### 5.4 DEBUG Circle

- `DEBUG_INFRA_RANGE_CIRCLE = true` (`infraRange.ts`)
- stroke: dashed 녹색 / **fillOpacity: 0** (내부 채움 없음)
- QA 종료 후 플래그 `false` 또는 코드 삭제

### 5.5 FE 완료 조건

- [x] 격자 미선택에도 인프라 마커 표시
- [x] 줌/이동 시 반경·마커 갱신
- [x] 주변 표시 OFF → 마커 전부 제거
- [x] 타입별 토글 필터
- [x] 격자 클릭 시 패널 상세만 (지도 마커는 view 유지)
